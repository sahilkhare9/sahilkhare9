## 👋 About Me

I'm a **Full-Stack Developer** based in Gwalior, India, currently pursuing my **Master of Computer Applications (MCA)** from Motilal Nehru National Institute of Technology, Allahabad.

I enjoy turning ideas into production-ready web applications — from designing clean frontend interfaces to building reliable backend services. My focus is on **writing maintainable code, learning continuously, and shipping things that actually work**.

- 🔭 **Currently building** — Full-stack web apps with real-world use cases
- 🌱 **Currently learning** — System design, cloud fundamentals (AWS), and advanced React patterns
- 💡 **Interested in** — Web performance, clean architecture, developer tooling
- 🎯 **Looking for** — Internship / entry-level opportunities in Full-Stack or Backend development
